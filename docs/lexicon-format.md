# 词库格式 (lexicon.json)

`lexicon/lexicon.json` 是可选文件。存在则覆盖内置默认词库，不存在则用内置的。
启动时读取一次（`core/plugin.py` 的 `load_lexicon_file()`）。

## 顶层结构

```json
{
  "note": "随便写，不参与逻辑",
  "运镜":    { ... },   // dict
  "镜头语言": { ... },   // dict
  "史诗":    { ... },   // dict
  "剧情":    [ ... ]    // list
}
```

四个键都可缺省。缺哪个就沿用内置的哪个。

## 运镜

```json
"推近": {
  "en": "Dolly in",
  "safe": true,
  "how": "相机向主体靠近",
  "param": "3-5s 推 8-12%，≤20 px/s",
  "risk": "推太多边缘出画"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `en` | 是 | 英文名，写进提示词 |
| `safe` | 是 | `false` 表示会改透视或需换视角，`plan` 不会选它 |
| `how` | 是 | 怎么做，拼进运镜指令 |
| `param` | 建议 | 速度/角度建议 |
| `risk` | 建议 | 风险说明，给人看 |

## 镜头语言

结构同「运镜」。注意：外部文件加载时分类会被合并成一张表，
`lexicon --category 镜头语言` 仍然可用，但不再区分「基础运动 / 特殊运动 / 景别角度 / 构图焦点」。

## 史诗

```json
"长推入画": { "how": "极慢的推进，慢到观众察觉不到，只感觉到接近", "safe": true }
```

## 剧情

list，每条一组完整提示词：

```json
{
  "no": 1,
  "name": "低位起手",
  "use": "开场 / 交代体量",
  "prompt": "6秒，单一连续镜头。机位贴台面高度，从产品一侧缓慢横移到正面……"
}
```

`no` 决定 `lexicon --category 剧情` 里的键名（`01 背影跟进`）。

## 替换建议

内置词库只是起步集。换成你自己的影视术语表时，保持上面字段口径即可，
`plan`、`lexicon`、海报文案都不需要改代码。
